# PROMPT_SPEC — THE MUSEUM OF ME

이 문서는 이 사이트가 **무엇을 기준으로 만들어졌는지** 정리한 것입니다.
원본 기획서는 `the_museum_of_me_website_prompt.md` 이며, 아래는 실제 구현에 반영된 결론과
작업 중 내린 판단입니다. 이어서 수정할 때 기준으로 쓰세요.

---

## 1. 콘셉트

| 항목 | 내용 |
| --- | --- |
| 한 문장 | 방문자가 전시품을 하나씩 열어 보며 양경준이라는 사람을 스스로 발견하는 개인 박물관 |
| 핵심 메시지 | 사람은 이력서보다 넓습니다 |
| 브랜드 문구 | `THE MUSEUM OF ME` / 내가 해 온 일들, 믿고 있는 것들, 그리고 아직 되어가는 중인 것들의 모음 |
| 우선순위 | 콘셉트와 내용 > 핵심 상호작용 > 시각적 완성도 > 부가 효과 |
| 태도 | “내가 대단하다”가 아니라 “이런 경험과 선택들이 나를 만들어 왔다” |
| 언어 | **화면의 모든 글은 한국어.** 전시품 제목 아래에만 영문 부제를 작게 둡니다 |

### 피한 것

- 검은 배경과 세리프 글꼴로 포장한 이력서
- 업무 자동화가 전체를 독점하는 구성
- 무거운 3D·영상·긴 인트로
- 근거 없는 성격 분석, 과장된 성과, 확인되지 않은 통계
- 환자정보·내부 자료·민감한 업무 화면
- 권리가 불분명한 이미지·글꼴·음악
- 화면에 드러나는 자리표시자(“[작성하세요]” 같은 미완성 흔적)

## 2. 구조

```text
입구
  └ 전시 관람 시작하기
전시실 안내
  ├ 처음부터 순서대로 보기 → 01부터 차례로
  └ 전시실 직접 선택
       전시실 01  나의 시작         나는 어디에서 시작했는가      (어두운 톤 · archive)
       전시실 02  생각하는 방식      나는 세상을 어떻게 보는가      (밝은 전시벽 · objects)
       전시실 03  내가 바꾼 것들     나는 무엇을 바꾸었는가        (어두운 톤 · documents)
       전시실 04  나를 움직이는 것   무엇이 나를 계속하게 하는가    (따뜻한 톤 · collection)
       전시실 05  아직 되어가는 중   나는 어떤 사람이 되어가는가    (여백이 넓은 톤 · sparse)
                   └ 맺음말: 전시 전체를 닫는 한 문단
```

- 단일 페이지 + 해시 라우팅 (`#/map`, `#/room/<id>`, `#/room/<id>/<전시품 id>`)
- 새로고침 없이 이동하고, 주소를 공유하면 그 화면이 바로 열립니다
- 전시품 상세는 **화면 전체를 쓰는 단독 전시 화면**입니다. 둥근 팝업 카드가 아니라
  그 전시실의 조명을 그대로 이어받아 전환됩니다
- 전시실 안내는 카드 격자가 아니라 **편집형 색인 + 전시 공간 평면도**입니다.
  목록에 포인터를 올리면 평면도의 해당 전시실에 조명이 들어옵니다
- **관람객 선택형 엔딩(Final Reflection)은 두지 않았습니다.** 마지막 전시실 아래의
  맺음말이 전시를 닫는 역할을 합니다. 선택지를 고르게 하는 방식이 성격검사처럼 보일 수 있고,
  전시의 결론을 방문자의 취향에 맡기는 구성이 이 전시의 메시지와 맞지 않았습니다.

### 전시품 (10점)

| 전시실 | 번호 | 전시품 |
| --- | --- | --- |
| 01 나의 시작 | 001–003 | 첫 번째 사진 / 학생이던 시간 / 첫 출근 |
| 02 생각하는 방식 | 004–005 | 계산기 / 질문이 적힌 메모 |
| 03 내가 바꾼 것들 | 006–007 | 직접 개발한 업무 자동화 프로그램 / 500만 번의 발걸음 |
| 04 나를 움직이는 것 | 008–009 | 운동 기록 / 같이 공부하는 사람들 |
| 05 아직 되어가는 중 | 010 | 빈 액자 |

> 번호는 `EXHIBITS` 의 순서에서 자동으로 매겨집니다. 데이터에는 적지 않습니다.

### 전시품 상세의 공통 구성

1. 전시품 번호 + 소속 전시실
2. 한글 제목 / 영문 부제
3. 사진 (없으면 선화) + 캡션
4. **이 전시품에 대하여** — 물건 자체
5. **이야기** — 실제 경험과 판단
6. **이 전시품이 말해 주는 것** — 관점·태도 + 키워드 태그
7. (필요할 때만) **전과 후** 수치와 그 범위를 밝히는 주석
8. 이전 / 전시실로 돌아가기 / 다음

## 3. 시각 디자인

### 색상 (styles.css `:root`)

| 변수 | 값 | 용도 |
| --- | --- | --- |
| `--charcoal` | `#191919` | 주요 텍스트, 어두운 전시실 |
| `--ivory` | `#F0ECE4` | 밝은 전시실의 기본 벽 |
| `--stone` | `#B9AC96` | 어두운 전시실의 포인트·보조 텍스트 |
| `--bronze` | `#776A56` | 밝은 전시실의 전시 번호·구분선 포인트 |
| `--white` | `#FFFFFF` | 여백이 넓은 전시실의 벽 |

전시실마다 `data-tone` 으로 조명을 바꿔 공간에 리듬을 만듭니다
(`dark` / `light` / `warm` / `air`). 어두운 전시실과 밝은 전시실이 번갈아 나오도록
배치했습니다. 포인트 색은 조명에 따라 자동으로 바뀝니다 — 밝은 방에서는 브론즈,
어두운 방에서는 스톤(`--room-accent`). 번호·구분선·작은 강조 외에는 쓰지 않고,
네온·글로우·유리 효과·의미 없는 그라데이션은 쓰지 않습니다.

### 글꼴

- 제목: Cormorant Garamond(영문) + Nanum Myeongjo(한글) — 두 글꼴을 한 스택에 두어
  영문과 한글이 같은 인상으로 이어집니다
- 본문·UI: Noto Sans KR
- 전시 번호·메타데이터: Noto Sans KR에 자간을 넓혀 씁니다. 세리프의 옛날식 숫자는
  `01` 이 `OI` 로 읽히기 때문에 번호에는 쓰지 않습니다
- 모두 Google Fonts(SIL OFL). 연결이 실패해도 시스템 명조/고딕으로 대체됩니다
- 한글 가독성을 위해 자간을 좁게(0.02~0.1em) 유지하고, 줄바꿈은 `word-break: keep-all` 로
  어절 단위를 지킵니다. 한글에는 기울임꼴을 쓰지 않습니다(가짜 이탤릭 방지)

### 모션

- 전환 160~420ms, 과한 확대·패럴랙스·3D 회전 없음
- 전시품에 포인터를 올리면 위에서 떨어지는 조명이 밝아지고 라벨의 선이 길어집니다
  (전시품이 들썩이거나 그림자가 커지는 효과는 쓰지 않습니다)
- 전시품을 넘길 때는 조명이 한 번 바뀌는 정도의 짧은 전환(360ms)만 둡니다
- 스크롤을 가로막거나 자동으로 다음 구간으로 보내지 않습니다
- `prefers-reduced-motion: reduce` 에서는 애니메이션을 제거합니다

## 4. 사운드 정책

- **자동 재생하지 않습니다.** 방문자가 버튼을 누른 뒤에야 `<audio>` 에 경로를 넣고 재생합니다
- 기본 음량 18%, 상단과 입구의 두 컨트롤이 서로 동기화됩니다
- 상태를 ‘소리 켜짐 / 소리 꺼짐’ 과 `aria-pressed` 로 표시합니다
- 전시실을 옮기거나 전시품을 열어도 음악이 다시 시작되지 않습니다
- **음원이 없으면** 컨트롤을 비활성화하고 “배경음악은 나중에 추가할 수 있습니다” 만 안내합니다
- 음향 방향: 느린 템포의 앰비언트 피아노와 패드, 넓은 잔향. 보컬·드럼·예고편식 타격음 없음

## 5. 기술

- HTML5 + CSS3(변수·Grid·Flexbox·미디어쿼리) + 바닐라 JavaScript, 외부 라이브러리 없음
- 서버·DB·로그인·분석 추적 없음. 모든 경로가 상대 경로라 GitHub Pages 에 그대로 배포됩니다
- 글은 `script.js` 의 `ROOMS` / `EXHIBITS` / `CLOSING` 한곳에 모여 있고,
  화면은 공통 렌더링 함수가 데이터를 보고 그립니다 (UI 복사·붙여넣기 없음)
- 사진이 없으면 전시품별 **인라인 SVG 선화**로 자동 대체되어 레이아웃이 깨지지 않습니다
- 이미지 틀은 4:5 고정 비율이라 로딩 중에도 화면이 튀지 않습니다
- 접근성: 키보드 전체 조작, 포커스 가둠과 복귀, `role="dialog"`/`aria-modal`,
  의미 있는 레이블과 대체 텍스트, 충분한 명도 대비, 가로 스크롤 없음

## 6. 내용에 관한 원칙 (가장 중요)

실존 인물의 홈페이지이므로 다음을 지켰습니다.

1. **제공받지 않은 일화·성격·수상·성과는 지어내지 않았습니다.** 날짜, 금액, 조직명,
   구체적인 사건은 어디에도 넣지 않았습니다.
2. 글은 **확인된 사실**과 그 일을 대하는 태도만으로 썼습니다 — 재무·회계 업무,
   구매·계약·비용 업무, 병원 운영·예약 관리, 직접 만든 업무 자동화 도구,
   MBA 수학 중, 운동과 기록을 이어 가는 생활, AI·전략에 대한 관심.
3. 그래서 화면에는 자리표시자가 없습니다. 대신 개인 일화로 바꾸면 좋은 자리를
   `README.md` 4장에 표로 정리해 두었습니다.
4. `약 50분 → 약 2분` 은 **그 작업 한 건의 결과**로만 쓰고, 전시품 안에 범위를 밝히는
   주석을 함께 두었습니다.
5. 이미 한 일과 앞으로 할 일을 구분합니다. 016 다음 실험에는 ‘계획’ 라벨이 붙습니다.
6. 환자정보·진료정보·내부 시스템·계약 원본은 어떤 형태로도 포함하지 않습니다.
   관련 전시품 캡션에 ‘재구성 예시 / 민감정보 제거’ 를 적어 두었습니다.
7. 성과가 자동화에 치우치지 않도록 프로세스 개선, 비용·계약, 측정과 검증을 함께 두었습니다.
