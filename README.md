# THE MUSEUM OF ME — 나라는 사람의 박물관

> 내가 해 온 일들, 믿고 있는 것들, 그리고 아직 되어가는 중인 것들의 모음.
> — 양경준 개인 전시

이력서를 화면에 옮긴 사이트가 아닙니다. 한 사람을 만들어 온 **물건·기억·성과·태도·미래**를
전시품으로 놓고, 방문자가 하나씩 열어 보며 그 사람을 발견하는 전시입니다.

- 전시실 5곳 · 전시품 10점 · 마지막 전시실의 맺음말로 마무리
- 화면의 모든 글이 한국어 (전시품 제목에만 영문 부제가 작은 글씨로 붙습니다)
- HTML + CSS + 바닐라 JavaScript (빌드 도구·서버·데이터베이스 없음)
- 사진과 음악이 **없어도 그대로 동작**하며, 파일만 넣으면 자동으로 반영됩니다

## 1. 실행하기

### 방법 A — 파일을 그냥 열기

`index.html` 을 더블클릭하면 브라우저에서 바로 열립니다. 모든 기능이 동작합니다.

### 방법 B — 로컬 서버로 열기 (권장)

```bash
# Python 이 있는 경우 (프로젝트 폴더에서)
python -m http.server 8000
#  → 브라우저에서 http://localhost:8000

# Node.js 가 있는 경우
npx http-server -p 8000 -c-1 .
```

VS Code 의 `Live Server` 확장으로 `index.html` 을 열어도 됩니다.

## 2. 파일 구조

```text
.
├── index.html     # 화면 뼈대 — 입구 / 전시실 안내 / 전시실 / 전시품 패널 / 전시 소개
├── styles.css     # 디자인 전부 — 색상 변수, 전시실 톤, 레이아웃, 반응형, 모션
├── script.js      # ★ 모든 글과 동작 (전시품 내용은 이 파일 위쪽에 모여 있습니다)
├── README.md      # 이 문서
├── PROMPT_SPEC.md # 기획·구성 요약
└── assets/
    ├── images/    # 사진을 넣는 곳 (_READ-ME-FIRST.txt 에 파일명 목록)
    └── audio/     # gallery-ambience.mp3 를 넣는 곳
```

| 고치고 싶은 것 | 열어야 할 곳 |
| --- | --- |
| 전시실 이름·질문·소개문 | `script.js` 의 `ROOMS` |
| **전시품의 모든 글과 사진 경로** | `script.js` 의 `EXHIBITS` |
| 마지막 전시실 맺음말 | `script.js` 의 `CLOSING` |
| 음악 경로, 기본 음량 | `script.js` 의 `CONFIG` |
| 색상·글꼴·여백 | `styles.css` 맨 위 `:root` |

`script.js` 의 “여기서부터는 UI 구현 코드입니다” 아래는 손대지 않아도 됩니다.

## 3. 전시품 글 수정하기

`EXHIBITS` 배열에서 전시품을 찾아 값을 바꾸면 화면이 자동으로 다시 그려집니다.

```js
{
  id: "calculator",              // 주소에 쓰이는 고유 id (#/room/thinking/calculator)
  roomId: "thinking",            // 소속 전시실
  title: "계산기",                // 화면에 크게 나오는 한글 제목
  titleEn: "The Calculator",     // 제목 아래 작게 붙는 영문
  tagline: "느낌과 사실을 갈라 주는 도구.",  // 전시실 벽면 라벨에 보이는 한 줄
  glyph: "calculator",           // 사진이 없을 때 쓰는 선화 (아래 목록 참고)
  crop: "square",                // 사진 비율 — portrait / tall / square / landscape / wide
  image: "calculator.jpg",       // assets/images/ 안의 파일명. 없으면 선화로 대체
  imageAlt: "전시대 위에 놓인 계산기",       // 대체 텍스트(접근성) — 꼭 채우세요
  caption: "계산기",              // 사진 아래 캡션 (앞의 "전시품 004 ·" 는 자동)
  object: "...",                 // 이 전시품에 대하여 — 물건 자체 설명
  story: ["...", "..."],         // 이야기 — 한 칸이 한 문단
  more: ["..."],                 // (선택) ‘조금 더 읽기’ 안에 접히는 내용
  reflection: "...",             // 이 전시품이 말해 주는 것
  reveals: ["분석적 사고"],        // 키워드 태그
  figures: [                     // (선택) 수치 비교 블록
    { label: "이전", value: "약 50분" },
    { label: "이후", value: "약 2분" }
  ],
  figuresNote: "이 수치는 ...",   // (선택) 수치의 범위를 밝히는 주석
  status: "계획",                // (선택) 액자 왼쪽 위에 라벨이 붙습니다
  noPhoto: true                  // (선택) 의도적으로 비워 둔 자리
}
```

> **번호는 적지 않습니다.** 전시품 번호(001, 002 …)는 `EXHIBITS` 에 적힌 **순서대로**
> 자동으로 매겨집니다. 전시품을 더하거나 빼거나 순서를 바꿔도 번호는 알아서 맞춰지고,
> 캡션 앞의 `전시품 004 ·` 도 자동으로 붙습니다.
>
> **전시품 수를 문장에 넣을 때**는 `{전시품수}` 라고 적으면 우리말 숫자로 바뀝니다.
> 전시실 `intro` 에서는 그 전시실의 전시품 수, `CLOSING.body` 에서는 전체 수입니다.
> 아라비아 숫자가 필요하면 `{숫자}` 를 씁니다.

### 선화(glyph) 이름

`photo` `cap` `door` `calculator` `question` `tool` `campaign`
`log` `people` `frame`

목록에 없는 이름을 적으면 `frame`(빈 액자) 선화로 대신 표시됩니다.

### 사진 비율(crop)

전시품을 모두 같은 크기로 자르지 않기 위한 값입니다. 사진이 담은 내용에 맞춰 고릅니다.

| 값 | 비율 | 쓰는 곳 |
| --- | --- | --- |
| `portrait` | 4:5 | 인물·세로로 긴 사진 (기본값) |
| `tall` | 5:7 | 더 길게 세우고 싶은 사진 |
| `square` | 1:1 | 책상 위 사물 |
| `landscape` | 3:2 | 공간이 보이는 사진 |
| `wide` | 16:9 | 화면 캡처, 도표 |

### 전시실 구성(layout)

`ROOMS` 의 `layout` 값이 그 전시실의 전시 방식을 정합니다. 전시실마다 다른 값을 써서
같은 배치가 반복되지 않게 합니다.

| 값 | 전시 방식 |
| --- | --- |
| `archive` | 사진을 높이를 어긋나게 걸어 둔 아카이브 벽 |
| `objects` | 사물과 설명이 좌우로 번갈아 놓이는 편집형 |
| `documents` | 대표 전시품 한 점을 크게, 나머지를 작게 |
| `collection` | 크기가 제각각인 개인 소장품 진열 |
| `sparse` | 여백을 크게 두고 띄엄띄엄 놓는 구성 |

`tone` 은 전시실 조명입니다. `dark`(어두운 전시실) · `light` · `warm` · `air` 중에서
고르고, 어두운 방과 밝은 방이 번갈아 나오도록 배치하면 공간에 리듬이 생깁니다.

## 4. 본인 이야기로 바꾸면 더 좋아지는 문단

지금 들어 있는 글은 **확인된 사실**(재무·회계 업무, 구매·계약, 병원 운영·예약 관리,
직접 만든 자동화 도구와 약 50분 → 약 2분, MBA 수학 중, 운동과 기록, AI·전략 관심)과
그 일을 대하는 태도만으로 쓴 것입니다. 지어낸 일화·날짜·수치는 넣지 않았습니다.

아래 자리에 실제 경험을 한두 문장씩 더하면 전시가 훨씬 구체적으로 읽힙니다.
문장을 지우고 새로 쓰면 되고, 그대로 두어도 글이 비어 보이지 않습니다.

| 전시품 | 더하면 좋은 내용 |
| --- | --- |
| 001 첫 번째 사진 | 사진 속 시기·장소, 그 시절에 대해 들었던 이야기 |
| 002 학생이던 시간 | 전공, 기억에 남는 수업이나 활동 |
| 003 첫 출근 | 처음 맡았던 업무, 그때 가장 어려웠던 점 |
| 004 계산기 | 숫자를 분해해 보고 판단이 뒤집혔던 실제 항목 |
| 005 질문이 적힌 메모 | 실제로 되물어서 바뀐 관행 한 가지 |
| 006 직접 개발한 업무 자동화 프로그램 | 어떤 반복 업무였는지 (환자·진료 정보는 제외) |
| 007 500만 번의 발걸음 | 캠페인을 기획하게 된 계기와 반응 |
| 008 운동 기록 | 어떤 운동을 어떤 주기로 하는지 |
| 009 같이 공부하는 사람들 | 그 사람들에게서 얻은 구체적인 관점 하나 |
| 010 빈 액자 | 의도적으로 비워 둔 자리 (고치지 않아도 됩니다) |

> **수치를 적을 때** — 직접 확인했고 공개해도 되는 값만 쓰세요. 006의 `약 50분 → 약 2분`
> 처럼 범위를 밝히는 주석(`figuresNote`)을 함께 두면 오해가 생기지 않습니다.

## 5. 사진 교체하기

1. `assets/images/` 에 사진을 넣습니다.
2. 파일명을 `EXHIBITS` 의 `image` 값과 맞춥니다. (목록: `assets/images/_READ-ME-FIRST.txt`)
3. 새로고침하면 선화 자리에 사진이 들어갑니다.

- **권장 비율 4:5 세로형.** 다른 비율은 가운데를 기준으로 잘립니다.
- 권장 크기: 긴 변 1200~1600px, 장당 300KB 이하
- 사진이 없거나 경로가 틀려도 **레이아웃은 깨지지 않습니다.** 자동으로 선화가 표시됩니다.
- `imageAlt` 는 꼭 채워 주세요. 화면을 못 보는 사용자가 듣는 설명입니다.
- 사진을 아예 쓰지 않을 전시품은 `noPhoto: true` 를 넣으면 선화만 보입니다. (017 빈 액자가 그렇습니다)

## 6. 음악 추가하기

1. `assets/audio/gallery-ambience.mp3` 로 음원 파일을 넣습니다.
   (다른 이름을 쓰려면 `script.js` 의 `CONFIG.audioSrc` 를 바꾸세요.)
2. 새로고침하면 상단의 소리 버튼이 활성화됩니다.

- **자동 재생하지 않습니다.** 방문자가 직접 켜야 재생됩니다.
- 기본 음량 18% (`CONFIG.defaultVolume`), 옆의 막대로 조절합니다.
- 전시실을 옮기거나 전시품을 열어도 음악이 끊기거나 다시 시작되지 않습니다.
- **파일이 없으면** 버튼이 ‘소리 없음’ 으로 비활성화되고 안내 문구만 뜹니다.
  오류 팝업은 없고 나머지 기능은 모두 정상입니다.

### 음악 권리 — 공개 전 확인

직접 만든 음원이나 웹사이트 사용이 허용된 라이선스 음원만 쓰세요.
영화·게임 OST처럼 권리가 불분명한 음원은 넣지 마세요. 사용한 음원은 아래에 기록해 두면 좋습니다.

```text
음원 제목:
제작자 / 출처:
라이선스(사용 조건):
확인한 날짜:
```

음악을 만들거나 찾을 때 쓸 설명문은 `assets/audio/_READ-ME-FIRST.txt` 에 있습니다.

## 7. GitHub Pages 배포

모든 경로가 상대 경로라 별도 설정 없이 그대로 올라갑니다.

```bash
git init
git add .
git commit -m "The Museum of Me"
git branch -M main
git remote add origin https://github.com/<사용자명>/<저장소명>.git
git push -u origin main
```

저장소에서 **Settings → Pages → Source: `Deploy from a branch`**, Branch 를 `main` / `(root)` 로
지정하고 저장하면 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

- 저장소 이름에 **공백·한글을 쓰지 마세요.** (예: `museum-of-me`)
- 사진·음악 파일도 함께 커밋해야 배포본에 포함됩니다.
- 전시실 주소는 `#/room/thinking`, 전시품은 `#/room/thinking/calculator` 형태라
  링크를 공유하면 그 화면이 바로 열립니다.

## 9. 조작 방법

| 동작 | 방법 |
| --- | --- |
| 입장 | `전시 관람 시작하기` |
| 전시실 이동 | 안내 화면의 카드 클릭 / 전시실 안에서 `←` `→` 키 |
| 순서대로 관람 | 안내 화면의 `처음부터 순서대로 보기` |
| 전시품 열기 | 카드 클릭, 또는 Tab 이동 후 `Enter` / `Space` |
| 전시품 넘기기 | 패널의 이전·다음 또는 `←` `→` 키 |
| 전시품 닫기 | `Esc`, 닫기(×), `전시실로 돌아가기`, 브라우저 뒤로가기 |
| 소리 켜기/끄기 | 상단 소리 버튼 (음량은 옆 막대) |

모든 조작이 키보드로 가능하며, 전시품을 닫으면 포커스가 원래 카드로 돌아옵니다.
운영체제에 ‘동작 줄이기(prefers-reduced-motion)’ 가 켜져 있으면 애니메이션이 자동으로 꺼집니다.

## 10. 점검 결과

실제 브라우저(Chrome)와 DOM 테스트로 아래를 확인했습니다.

- 입장 → 전시실 안내 → 5개 전시실 → 전시품 상세 → 마지막 전시실 맺음말까지 전체 흐름
- 전시품 키보드 조작(Enter·Esc·←·→), 포커스 복귀, 브라우저 뒤로가기
- 사진이 하나도 없는 상태에서 레이아웃 유지 (선화 대체)
- 음원이 없을 때 오류 없이 동작, 있을 때 재생·음량·상태 표시
- 데스크톱(1440px)·모바일(390px)에서 가로 스크롤 없음
- 브라우저 콘솔에 스크립트 오류 없음 (아직 넣지 않은 이미지의 404 기록만 남습니다)
